# 평가 (담당: 지영)

같은 질문셋으로 세 조건의 정답률을 비교함.

| 조건 | LLM에게 주는 입력 | SQL 작성 주체 |
| --- | --- | --- |
| A | 질문 + 테이블 구조 | LLM |
| B | 질문 + 테이블 구조 + 정의 문서 | LLM |
| C | 질문 + 온톨로지 도구 | Ontology Service |

| 파일 | 내용 |
| --- | --- |
| `questions.yaml` | 질문, 정답 값, 정답 SQL (20~30문항) |
| `run_eval.py` | 조건별 3회 실행, 결과를 DB에서 실행해 정답과 비교 |

A와 B는 서비스 없이 LLM과 DB만으로 돌릴 수 있으므로 먼저 진행하고, C는 서비스와 에이전트가 연결된 뒤 진행함.
